GITHUB — INTEGRACIÓN
=====================

- social-preview.png (1280x640): subir en Settings > General > Social
  preview del repositorio.

- favicon.ico (16/32/48): usar en GitHub Pages (docs/favicon.ico) o
  en el sitio marketing de la app.

- spidermapp-icon.svg / spidermapp-icon-512.png: para el header del
  README (badge o logo).

- spidermapp-wordmark.svg (fondo claro) y spidermapp-wordmark-dark.svg
  (fondo oscuro): usar según el modo de color del README con:
